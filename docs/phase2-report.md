# フェーズ2 完了報告

2026年10月26日。トップと3つのツールページまでを実装しました。フェーズ3以降の集客ページには着手していません。デプロイしていません。

## 実装

- `/`：3ツールへの入口、利益別手取り早見表の抜粋、6つの職業・独立モデルケース、ガイド目次。モデルケースから入力条件を引き継ぎます。
- `/tools/tedori/`：手取り、月額、手取り率、税・保険料内訳、同じ手取りの会社員年収、8段階のしくみ、12か月の支払いカレンダー、節税ヒント。
- `/tools/houjinka/`：個人・法人比較、役員報酬の自動探索と手動指定、利益ごとの損益グラフと数値表、法人化チェックリスト。
- `/tools/invoice/`：4方式の消費税額、現行年の最安比較から3割シナリオを除外、登録・未登録の比較。
- 全ツールで入力をURLクエリに反映・復元、条件付きURLのコピー、不正入力表示。入力額は万円、URLのblueのみ円。非有限値・負値・100,000万円を超える入力は拒否し、入力エラー時は最後に計算できた結果を保持してその旨を表示します。
- 広告内容はsrc/data/offers.tsへ抽出。元の分岐条件、PR表示、rel="sponsored noopener"を維持。仮URLは#、準備中と明記して遷移を抑止しています。
- 静的生成とブラウザー更新に同じ計算・描画関数を使用し、JavaScript無効時も初期例の結果を表示します。
- 公開URL未定のnoindex、暫定税制バッジを維持しています。params.tsはフェーズ1から変更していません。
