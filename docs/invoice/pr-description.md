# インボイス計算の年分連動と登録比較を修正

- 年分から経過措置の年間実効割合を自動計算。毎月の売上が均等という前提を明示し、手動上書きと旧URLの明示割合も保持。
- 2割・3割特例と簡易課税を基準期間の売上・登録理由・除外条件で判定。対象外カードは金額を隠して理由を表示。
- 非登録でも課税となる条件では、免税を仮定した差額を断定しない。
- 結論と年差額を先頭に配置。登録・非登録の比較、損益分岐、値下げ要求割合、2026〜2031年のSVGと同データの表を追加。
- 主入力を4項目に整理。個人事業主専用の前提・年度バッジ・ナビへ変更し、方法カードに計算式・開閉式の適用条件・簡易課税の届出情報を掲載。
- 仮広告は環境変数で明示的に有効にした場合だけ表示。インボイスは請求書ソフト・会計ソフトを優先。
- 数値入力の全角・カンマ、コピーの通知、金額要約のpolite読み上げ、スマートフォンの結果移動を整備。
- 旧フラグメントURLでも、前提を開いた後に入力条件を失わないよう修正。旧プロトタイプ互換は維持。

検証：npm test 106件成功、npm run check、PUBLIC_SITE_URL=https://okuritsu-soroban.com npm run build。375px・1280pxで年度切替、手動設定、URL復元、適用条件、結果移動、グラフ・表、横はみ出しを確認。コピー通知は利用者のクリップボードを変更しないAPI置換で成功・失敗を検証。

固定ケース（売上700万円・課税経費80万円・事業者向け90%・第5種・特例要件を満たす・値下げ要求100%）：

| 年分 | 自動実効割合 | 最安税額 | 値下げ目安 | 比較の差 |
| --- | --- | --- | --- | --- |
| 2026 | 77.5% | 2割特例140,000円 | 141,750円 | 登録が1,750円有利 |
| 2027 | 70% | 3割特例210,000円 | 189,000円 | 非登録が21,000円有利 |

出典：[国税庁・令和8年度インボイス改正](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm)、[国税庁・簡易課税](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6505.htm)。

制約：標準税率10%、単一業種、課税仕入れ全額控除、年次比較の入力条件固定、概算の端数処理。所得税等を引いた最終手取りの比較や、特例の全要件の認定ではありません。
