# 個人事業税の記事で確認した公式資料

確認日：2026-11-03。税率・業種表の追加が対象。計算パラメータと従来の税計算コードは変更しない。

1. 東京都主税局「個人事業税」：https://www.tax.metro.tokyo.lg.jp/kazei/work/kojin_ji/
   - 法定業種70業種の区分、代表例、第1種5%・第2種4%・第3種原則5%と一部3%を確認。
   - 第3種の3%には医業類似事業・装蹄師業が含まれる。3%区分を省略しない。
   - 都の説明が引用する地方税法の条項、青色申告特別控除を加算する扱い、事業主控除と対象事業を区別。
2. 地方税法： https://laws.e-gov.go.jp/law/325AC0000000226
   - Webテキスト表示では本文を抽出できなかったため、公式法令APIのXML https://laws.e-gov.go.jp/api/1/lawdata/325AC0000000226 で条文を照合。
   - 第72条の2第3項・第8〜10項：個人の第1〜3種事業の課税と業種の列挙。
   - 第72条の49の17第1項：標準税率5%・4%・5%・3%。同第2項：兼業時の所得の按分。

## 本文での区別

文筆・純粋な創作の例は、限定列挙された法定業種と照合するための説明上の例（一覧に基づく解釈）であり、都税事務所の個別の非課税認定事例を転載したものではない。広告・編集の請負・デザイン・販売等を含む場合は別途確認と明示する。エンジニア・デザイナーの肩書だけで対象外・対象を断定しない。
