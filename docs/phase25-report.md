# フェーズ2.5：令和8年・令和8年度更新

公式資料の出典と確認日はparams.tsとparams-check.mdに記録。国保4区分はそれぞれに上限を適用し、合計後の100円未満切捨ては従来の概算方式を維持。単身成人・軽減なし。社会保険は等級の近似と年度率の12か月適用を維持し、暦年の実際の払込額ではない。

給与所得控除は令和8年分の最低保障額、220万円未満の特則、660万円未満の別表の4,000円刻みを適用。インボイスは80/70/50/30/0%の期間表示と既定70%、2年前の売上・登録経緯・除外条件・対象年を入力して特例を判定する。3割特例の対象は2027・2028年分で、2026年分の最安比較に混ぜない。

法人化の中立域はparams.tsのcorporationNeutralThreshold=300,000円。±30万円未満を「ほぼ同じ」とし、+30万円以上は法人、−30万円以下は個人に多く残る旨を表示する。
