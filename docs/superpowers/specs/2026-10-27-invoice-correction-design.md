## 技術とOSSの選定

既存のAstro static、TypeScript、CSS、Vitestを継続。依存追加なし。画面金額はすべてsrc/lib/taxから生成。Web Workerや新APIは不要。年次推移はSVG＋同じデータの表で表示する。

参考OSSはTabler（https://github.com/tabler/tabler）。Webアプリ開発者・業務利用者向けにダッシュボードの情報階層と入力・比較表示を統一するUIキット。HTML・Bootstrap 5・Sass/CSS変数を使用、MIT、2026-10-27確認時の最新リリースはv1.7.1（10月23日）。セキュリティの保証や日本の税制実装の根拠には使わない。外部ライブラリには別ライセンスがあるため同梱はしない。KPIと比較の強調、補足の開閉、一貫した部品設計を参考にし、高密度の管理メニューやBootstrap・グラフライブラリの全面導入は避ける。代替のPrelineはTailwind・プラグイン層と追加ライセンス条件が既存構成に合わない。税制根拠は以下の国税庁資料のみとする。

## 公式資料と計算上の前提

- 改正・2割/3割・経過措置: https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm
- 簡易課税・基準期間・届出期限: https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6505.htm
- インボイス制度: https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6498.htm

個人事業主専用と冒頭に明記する。法人モードは今回の範囲に加えない。年内に割合が変わるため、売上が毎月均等という仮定で月数按分する。これは法定の年間一律割合ではなく、年間比較用の実効値であることを明記。

| 年分 | 自動設定する実効割合 |
| --- | --- |
| 2026 | 77.5%（1〜9月80%、10〜12月70%） |
| 2027 | 70% |
| 2028 | 65%（1〜9月70%、10〜12月50%） |
| 2029 | 50% |
| 2030 | 45%（1〜9月50%、10〜12月30%） |
| 2031 | 22.5%（1〜9月30%、10〜12月0%） |

詳細に「自動/手動」を設ける。自動時は年分変更で再計算、手動時は上書きである旨を表示。旧共有URLのratio指定も手動値として復元し、無断で条件を変えない。新たに年度と自動/手動を共有URLへ保存する。

基準期間の課税売上は「1000万円以下／1000万円超〜5000万円以下／5000万円超」の3区分で取得し、特例と簡易課税を同じ区分から判定する。従来のbaseEligible=falseだけのURLは5000万円以下か判断できないため、未確認として確認を促す。判定できない方法を適用可能と断定しない。

値下げは、控除できない消費税相当額×事業者向け割合×値下げ要求割合（0〜100%、初期値100%）。初期値は依頼の完了ケースと整合させる。消費税と値下げのみの比較で、所得税・住民税・社会保険料まで差し引いた手取りではないことを示す。非登録でも本来課税事業者になる条件は別途注意し、非登録＝免税と誤解させない。

損益分岐は登録時の最安税額と値下げ額が一致する割合。事業者向け割合・値下げ要求割合の双方を算出し、分母0、0%、100%、100%を超える場合、同額、売上0を区別する。年次推移は売上・経費と適用判定の入力条件を固定した制度比較とし、将来の売上予測や将来の基準期間売上の保証にはしない。

## 画面構成と実装範囲

A. 計算修正を先行し、2割/3割/簡易/本則の適用可否と理由、年間実効値、値下げ、差額、損益分岐を純粋関数から返す。旧プロトタイプのテストは旧版互換として維持する。

B. 添付のUI改善5〜12を全て対象にする。
- 最上部に登録/非登録の差額、直下に2つの比較カードと差額バッジ。値下げなしの結果も併記。
- 主入力は売上・課税経費・年分・事業者向け売上割合。残りは詳細設定にまとめる。
- 第5種を初期値とし具体例を補う。スマホのボタンは更新後の結果へ移動する「結果を見る」。入力不備時はエラー箇所へ。
- 損益分岐を割合スライダーの目盛りにも表示。値下げ要求割合は詳細設定へ。
- 2026〜2031年の年次比較グラフと表。同条件で損得が反転する年を強調。
- 適用できない方法カードは金額を表示せず対象外理由を示す。可能な方法は計算式を1行、適用条件はカード内details。簡易課税に届出と移行期限の公式出典。
- インボイス専用の前提・年度バッジに変更。ヘッダーの機能リンク・矢印付き導線・ツールタブの重複は、このページではツール切替タブへ集約。ロゴのホームリンクとフッターは維持。
- 仮広告は環境変数が有効な場合だけ表示し、既定の本番では非表示。表示時の順は請求書ソフト・会計ソフト。PRとrel属性は維持。
- コピー時は共有のstatusトースト。金額に読み上げ更新、helpは名前・関連付け・キーボード操作を整える。表示更新のたびに全説明を読み上げないよう、金額要約の領域に絞る。

## 開発順序と完了条件

1. 年度・適用条件・基準期間・実効値・値下げ・境界のテストを追加し、現状で失敗することを確認。
2. 計算関数とURL状態の自動/手動切替、旧URL互換を実装。
3. 比較ヘッダー、入力、カード、損益分岐、年次推移、インボイス専用の前提・ナビ・広告・共有を実装。
4. npm test / npm run check / 本番URL指定build、375px・1280pxの操作と横はみ出しを確認。
5. 変更点・根拠・検証を箇条書きのPR説明として保存し、画面を報告。実装確認後、公開の指示に従う。

固定する完了例は依頼文のとおり：2026年・売上700万円・課税経費80万円・事業者向け90%・第5種・特例要件を満たす場合、2割140000円、値下げ141750円、3割対象外。2027年同条件は3割210000円、2割対象外。値下げ要求割合は100%、経過措置は自動を前提とする。
