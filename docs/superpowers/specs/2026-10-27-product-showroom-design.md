# パソコンから計算画面へつなぐUI

2026-10-27、利用者がPC・スマートフォンの案②を選択し、計算画面の説明を整理する方針を承認。

## 意図と範囲
日本のフリーランスと独立を検討する人が、手取り・法人化・資産形成の機能を短い紹介で理解し、そのまま計算できるようにする。トップは実写風のパソコンと実際の税計算から生成する画面を組み合わせる。白・淡いピンク・青緑・控えめなコーラルで全画面を統一。既存URL、記事、公式出典、広告条件、税・資産計算は維持する。公開作業は今回の範囲外。

紹介→機能の要約→手取り計算→億率の簡易計算→独立準備・早見表・記事へ自然なドキュメントスクロールでつなぐ。上のボタンから計算へ直接移動できる。強制スクロールやスクロール乗っ取りは行わない。スマートフォンは1列。

## 計算画面
主要な入力と結果を常時表示。追加条件はdetails、用語説明はクリック・タッチ・キーボードで開く共通の「？」。概算・対象地域・掛金支出前の手取りの意味と投資免責、入力不備は隠さない。結果内訳・しくみ・支払いカレンダーは開閉可能とし、既存の#shikumi/#calendarは開いて到達できるようにする。URLで復元した追加条件の要約を常時表示。入力エラーが折りたたみ内にあれば開いて修正可能にする。入力変更時は今までどおり自動更新し、計算ボタンも使える。

## OSSの比較・選定
参照: https://github.com/tabler/tabler / https://github.com/tabler/tabler/releases / https://github.com/htmlstreamofficial/preline

| 観点 | Tabler（選定） | Preline |
| --- | --- | --- |
| 課題・対象 | Webアプリやダッシュボードの情報階層を統一。開発者・業務利用者向け | TailwindによるWeb UIの部品と操作の統一 |
| 技術 | HTML・Bootstrap 5・Sass/CSS変数 | Tailwind CSS・TypeScriptプラグイン |
| 安全性 | MIT。外部ライブラリのライセンスは別。プロジェクト全体の安全性を保証する調査は行っていない | MITに加えFair Use条件。ポップアップの位置や依存ライブラリも確認が必要 |
| 更新 | 2026-10-27確認時、最新リリースv1.7.1（10月23日） | リリースが継続、ただし導入しないため個別版の追跡は対象外 |
| 再利用する設計 | KPIを主役にし、入力・内訳・補足を分ける。トークンと共通部品で統一 | 補足情報を必要時に表示する考え方 |
| 避ける点 | 業務向けの高密度なサイドバー、Bootstrap全体・グラフ依存の追加 | 現構成へのTailwind・プラグイン層の追加 |

設計の参考だけとし、OSSコードはコピーしない。Astro static・素のTypeScript・既存CSSを継続し、新たなUI依存は追加しない。

## 構成と実装順序
1. 共通のHelp/Disclosure、トークン、ヘッダーを整える。
2. 手取り・法人化・インボイス・億率の入力と結果の情報階層を整理。
3. PC画像＋HTMLの実計算プレビュー、トップの実計算欄を組み込む。
4. npm test / npm run check / PUBLIC_SITE_URL=https://okuritsu-soroban.com npm run build。375px・1280px、ヘルプ、折りたたみ内のエラー、URL復元、既存アンカーを確認。SEO対象60ページを維持。独立した検証用監査やLighthouseの追加実行は、以前の利用者指示に従って省略。
