# フェーズ2.5・3 完了報告

2026年10月26日。フェーズ2.5の更新を検証・コミットした後、フェーズ3まで実装しました。フェーズ4以降と公開・デプロイには進んでいません。

## 令和8年・令和8年度への更新

国保は医療・後期支援・介護・子ども支援の4区分を持ち、区分別に上限を適用します。健康保険9.85%、介護1.62%、被用者保険の子ども支援0.23%、一般の雇用保険本人0.50%へ更新しました。給与所得控除は国税庁令和8年分の最低74万円と特則・端数処理に対応しました。

インボイスは経過措置を80/70/50/30/0%と期間表示に変更し、初期値70%。3割特例は対象年2027/2028、基準期間の売上、登録経緯、除外条件の入力で判定します。2026年分の最安比較には3割特例を混ぜません。

法人化の結論はparams.tsに定めた年30万円の中立域を使用。±30万円未満は「ほぼ同じ」、+30万円以上は法人、−30万円以下は個人に多く残ると表示します。将来の年金や手続きも考える案内を含めています。

出典・適用日はparams.tsとparams-check.md、反映の詳細はphase25-report.mdに記録しました。国保は単身成人・軽減なし、社会保険は年度率の通年適用と標準報酬の近似、法人の配当などは引き続き概算です。
